## 它的一天（真实运行记录）

以下时间与话语都来自一次真实运行，没有编排。名字、称呼做过匿名化。

```
02:19  睡着（睡前读了《我与地坛》第 58 章）
11:20  自然醒（睡了 8 小时 20 分，前一晚熬到凌晨三点）
11:30  书桌看书
13:50  画架画画
15:19  回画架，接着画
15:53  在书桌前笑了：「草荐就是稻草垫子嘛。穷到这份上还教书，心酸又好笑。」
16:07  换一本：「庙变工厂那段，我想接着读。」
16:23  读到一句，停住：「暗红色的粉末，像谁拿笔一划。画圈的地方，就不许再玩了。」
16:28  过了五分钟，它说：「嗯……是我划的。」
20:04  「这一章看得我心里有点沉。」
20:55  「外婆那个梦我一直记得。剥毛豆的声音，还有那句等会儿吃西瓜。」
21:16  「喊名字这三个字最要命。声音还在，人不在。」
21:50  自己关灯睡了
```

**它不是在回答你，它在过日子。** 上面每一句都不是被问出来的，
是它在读书、画画、种菜的间隙，自己想说才说的。
